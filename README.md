# 🎬 Sorteio Cinema

Uma aplicação web interativa para realizar sorteios de assentos em uma sala de cinema.

## 📋 Funcionalidades

- ✅ **Configurar Sala**: Escolha o número de fileiras (A-Z) e quantidade de assentos (0-100)
- ✅ **Visualizar Sala**: Veja todos os assentos dispostos por fileira
- ✅ **Sorteio Aleatório**: Clique para sortear um assento aleatoriamente
- ✅ **Interface Responsiva**: Funciona em desktop, tablet e mobile
- ✅ **Design Moderno**: Interface intuitiva e agradável
- ✅ **Sorteios Múltiplos**: Realize quantos sorteios desejar

## 🚀 Como Usar

1. Abra o arquivo `index.html` no navegador
2. Configure o número de fileiras e assentos usando os sliders
3. Clique em "Criar Sala"
4. Clique em "REALIZAR SORTEIO" para sortear um assento
5. O resultado será exibido em destaque
6. Use "Novo Sorteio" para sortear novamente ou "Voltar à Configuração" para mudar as configurações

## 📝 Especificações

- **Fileiras**: De A até Z (máximo 26)
- **Assentos por Fileira**: De 1 até 100
- **Resultado**: Exibe fileira (letra) + número do assento
